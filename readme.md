## Descripcion del Proyecto
Este proyecto permite ingresar una lista de amigos, mostrar los nombres en una lista y realizar un **sorteo aleatorio** para seleccionar un amigo secreto.

---

## Estado del Proyecto
**Version actual:** 1.0  
 **Ultima actualizacion:** September 2025  
El proyecto se encuentra **completado** y listo para su uso.

---

## Demostracion de Funciones y Aplicaciones
- Ingresar nombres en una lista.
- Validar campos vacios antes de agregar un nombre.
- Mostrar los nombres en pantalla dinamicamente.
- Sortear un amigo al azar usando `Math.random()`.
